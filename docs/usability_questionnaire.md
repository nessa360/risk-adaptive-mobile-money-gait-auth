# E6 Usability and Authentication Friction Questionnaire

This instrument is a template only. No responses are included in this repository and no perceived-friction result may be reported until participants provide informed consent and complete the protocol.

Participants should complete a comparable mobile-money task under the normal authentication flow and the gait-assisted risk-adaptive flow. After each condition, record the number of unexpected interruptions, whether a step-up was completed successfully, and whether the participant would accept the additional authentication in normal use.

Use a five-point response scale from 1 (**strongly disagree**) to 5 (**strongly agree**) for the statements below:

1. The authentication process was easy to understand.
2. The authentication process interrupted my task unnecessarily.
3. I felt confident that the system protected the transaction.
4. I would accept this authentication process for low-value transactions.
5. I would accept this authentication process for high-value transactions.
6. The number of additional authentication requests was acceptable.

Report response counts, medians, and interquartile ranges only after data collection. False step-up rate should be calculated independently from the classifier decision logs as unnecessary step-ups among labelled genuine low/medium-risk transactions.
